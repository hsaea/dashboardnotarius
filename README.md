# Expert-Docs — дашборд ЗП помічників нотаріуса

Збирає виграні угоди з Kommo (воронка **Expert-Docs** `9126955`, статус **«Успішно реалізовано»** `142`),
групує по відповідальному за документи (поле **«Хто готує довіреність?»**) і рахує ЗП
за кількістю актів і підписів.

## Формула ЗП
```
ЗП = К-ть підписів × 220 + К-ть актів × 330   (грн)
```
Ставки редагуються в інтерфейсі CEO (за замовчуванням 220 / 330).

## Період
Старт — з **жовтня 2026** (архів) + **листопад 2026** (поточний). Змінюється у `.env` → `SINCE_MONTH`.

## Ролі
- **CEO** — бачить обох помічників, фільтр по помічнику і місяцю, редагує ставки.
- **Помічник** (Віта, Катерина) — бачить лише свої дані, ЗП, архів по місяцях і журнал угод.

## Авто-архівування
Кожного **1-го числа** попередній (завершений) місяць автоматично фіксується в архів —
його підсумки й журнал більше не змінюються. Поточний місяць завжди починається з 0 і
накопичується наживо. Перевірка виконується на старті сервера та щогодини (ручних кнопок немає).

## Запуск (локально)
```bash
npm install
npm start
```
Відкрити http://localhost:3000

При першому запуску створюються акаунти, паролі друкуються в консоль і зберігаються у
`data/initial-credentials.txt`.

## Перевірка даних
```bash
npm run verify
```
Друкує агрегати напряму з Kommo для звірки з дашбордом.

## Налаштування (`.env`)
| Змінна | Призначення |
|---|---|
| `KOMMO_SUBDOMAIN` | піддомен акаунта (frankohold) |
| `KOMMO_TOKEN` | довготривалий токен Kommo |
| `SINCE_MONTH` | з якого місяця тягнути дані (`YYYY-MM`) |
| `SIGN_RATE` / `ACT_RATE` | початкові ставки |
| `CACHE_TTL` | TTL кешу Kommo, сек |
| `PORT` | порт сервера |

## Деплой на VPS (пізніше)
1. Скопіювати проєкт, `npm install --omit=dev`.
2. Створити `.env` (не комітиться).
3. Запустити через pm2: `pm2 start src/server.js --name expert-docs`.
4. За потреби — reverse-proxy (nginx) + HTTPS.
